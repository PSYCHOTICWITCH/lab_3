Первый массив, размерностью n х m, заполняется данными, вводимыми с клавиатуры, так что заполнение ведется по столбцам от последних элементов столбца к первым.  
Второй массив, размерностью n х n, заполняется случайными числами так, что в каждом столбце получается возрастающая последовательность элементов.

### Алгоритм решения
Первый массив:
1. Получить n = GetLength(0) (строки), m = GetLength(1) (столбцы).
2. Для i от 0 до n-1 (строки сверху вниз):
 1. Вывести «Строка i+1».
 2. Для j от 0 до m-1 (столбцы слева направо):
  1. В цикле while читать строку и int.TryParse, пока не получится корректное число.
  2. Записать число в array[i, j].
Второй массив:
1. Создать Random.
2. n = GetLength(0).
3. Для i от 0 до n-1 (строки сверху вниз):
 1. Для j от 0 до n-1 (столбцы слева направо):
  1. Сгенерировать element = rand.Next(100, 1000).
 2. Если i != 0 (не первая строка):
  1. Пока element <= array[i-1, j] (не больше элемента сверху в этом же столбце):
  2. Перегенерировать element = rand.Next(100, i * 1000) (чтобы гарантировать, что цикл не уйдет в бесконечность, если предыдущий элемент максимальный из заданного диапазона).
 3.Записать array[i, j] = element.
Третий массив:
Алгоритм поиска простых чисел:
1. not_simple = false, num передается в функцию.
2. Бесконечный цикл:
 1. num++ — перейти к следующему числу-кандидату.
 2. Для i от 2 до ⌊√num⌋ включительно:
  1. Если num % i == 0 → not_simple = true, выйти из for.
 3. Если not_simple == true:
  1. Сбросить: not_simple = !not_simple (то есть false).
  2. Продолжить while (взять следующего кандидата).
4. Иначе (not_simple == false, делителей не нашлось) → вернуть num (это простое).
Алгоритм собственно заполнения массива:
1. element = 2 — первое простое.
2. n = GetLength(0).
3. Для i от 0 до n-1:
 1. Для j от 0 до n-1:
  1. array[i, j] = element — записать текущее простое в ячейку.
  2. element = NextSimple(element) — получить следующее простое для следующей ячейки.

# Задание 2
## Задача 11
### Текст задачи
В двумерном массиве записаны по m оценок n школьников. Укажите номера школьников, средняя оценка которых больше 4.5. 
### Алгоритм решения
1. was_marks = false — флаг «нашли хоть одного».
2. n = GetLength(0) — число школьников, m = GetLength(1) — число оценок.
3. Вывести заголовок.
4. Для каждого школьника i от 0 до n-1:
 1. marks_sum = 0 — обнулить сумму оценок этого школьника.
 2. Для каждой оценки j от 0 до m-1:
  1. marks_sum += array[i, j] — накопить сумму.
 3. marks_avg = marks_sum / m — средняя оценка школьника.
 4. Если marks_avg >= number (number = 4.5):
  1. was_marks = true.
  2. Вывести i + 1 (номер школьника с 1, а не с 0).
5. Если was_marks == false — вывести «таких нет.».

# Задание 3
## Задача 11
### Текст задачи
Ат-Вт+2*С 
### Алгоритм решения
1. Задать n, m. Создать A(n×m), B(n×m), C(m×n). Заполнить (случайно или вручную).
2. Транспонирование A: At = A.T():
 1. для i от 0 до m_A−1 (= m), для j от 0 до n_A−1 (= n):
 2. At[i, j] = A[j, i] → размер m × n.
3. Транспонирование B: Bt = B.T() — аналогично → m × n.
4. Вычитание: D = At - Bt:
 1. проверить совпадение размеров (m×n == m×n);
 2. для всех i, j: D[i, j] = At[i, j] - Bt[i, j].
5. Умножение на 2: E = 2 * C:
 1. для всех i, j: E[i, j] = C[i, j] * 2.
6. Сложение: R = D + E:
 1. проверить размеры (m×n == m×n);
 2. для всех i, j: R[i, j] = D[i, j] + E[i, j].
7. Вывести R через ToString().
